# 🛡️ PhishGuard – Phishing & Fraud Detection System

**Stay Alert. Stay Secure. Stay Protected.**

PhishGuard is a web-based cybersecurity project designed to help users identify potentially suspicious messages, URLs, and mobile numbers. It provides basic security checks and highlights possible warning signs to help users stay aware of online threats.

---

## 📌 About the Project

Online scams and phishing attempts are becoming increasingly common. People may receive suspicious messages, unknown links, or unexpected calls and messages.

PhishGuard aims to make basic fraud awareness easier through a simple web interface where users can check suspicious information and understand potential risks.

This project was developed as a student project to explore web development and basic cybersecurity concepts.

## ✨ Features

- **Message Phishing Detection:** Checks message content for suspicious words and common phishing indicators.
- **URL Analysis:** Examines submitted URLs for potentially suspicious characteristics.
- **Mobile Number Checker:** Performs basic checks on submitted mobile numbers.
- **Risk Assessment:** Displays results based on the checks performed.
- **User-Friendly Interface:** Simple and responsive interface for easy navigation.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/vaishnavijiman14/PhishGuard.git
```

**2. Open the project folder**

```bash
cd PhishGuard
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the Flask application**

```bash
python app.py
```

**5. Open your browser**

Visit:

```text
http://127.0.0.1:5000/
```
